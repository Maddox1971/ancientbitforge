Lyra Recorder Privacy Policy

Last updated: 18 July 2026 · Application version: 1.0.0+2

1. OVERVIEW

This Privacy Policy explains how Lyra Recorder (the “Application”), developed by Ancient BitForge, accesses, processes, stores and deletes user data. Lyra Recorder is a mobile audio recording tool for voice, field and reference recording.

The Application follows a local-first model. Microphone audio, recordings, recording markers, calibration measurements and settings are processed and stored on the user’s device. The Application does not create user accounts, require login, use advertising or analytics SDKs, or transmit recordings to Ancient BitForge servers.

2. PERMISSIONS AND DATA ACCESS

Lyra Recorder requests only the Android permissions needed for recording and local file management. A permission is used only when the user activates the related function.

  • Microphone (RECORD_AUDIO). Required to capture audio through the device microphone or a supported external audio input. The audio signal is processed locally for recording, level metering, waveform and spectrum display, gain control, high-pass filtering, limiter operation and session calibration.
  • Legacy file permissions. On Android 9 and earlier, WRITE_EXTERNAL_STORAGE may be used to create or manage audio files. On Android 12L and earlier, READ_EXTERNAL_STORAGE may be used to access audio files selected by the user. On newer Android versions, the Application uses app-specific storage and the Android system file picker. It does not scan unrelated personal files.
  • Haptic feedback. The interface may provide tactile feedback when controls are used. This does not require Lyra Recorder to collect or transmit personal data.

3. DATA COLLECTION AND THIRD-PARTY SERVICES

No developer-side collection. Ancient BitForge does not receive or store recordings, microphone content, waveform data, spectrum data, markers, calibration measurements or usage analytics from the Application.

No advertising or analytics. The Application contains no advertising SDK and no third-party analytics SDK.

No payments in this version. Application version 1.0.0+2 does not implement an in-app purchase flow and does not process payment information. If a future release introduces Google Play Billing, this Policy and the Google Play Data safety declaration will be updated before that feature is made available.

Google Play services. Google Play may process limited device, account, download, update, integrity and transaction-related information under Google’s own privacy terms when the Application is distributed or reviewed. Ancient BitForge does not receive payment-card details.

External browser and Android file picker. When the user opens this Privacy Policy, the Application hands the web address to the device’s browser. When the user imports an audio file, the Android system picker is used. Those external components are governed by their respective providers’ privacy practices.

4. LOCAL PROCESSING AND SETTINGS

Microphone capture, gain control, high-pass filtering, limiter processing, real-time meters, waveform generation, spectrum visualization, playback tracking, recording markers and calibration calculations are performed locally on the device.

The Application may retain local preferences such as the selected recording format, calibration state, thresholds, recording options and interface state. These preferences are used only to operate the Application.

5. RECORDINGS, MARKERS AND IMPORTED FILES

Recordings created by Lyra Recorder are stored in the Application’s app-specific local storage. They are not uploaded automatically. Recording markers and their associated text are stored locally alongside the relevant recording session where applicable.

The user may select compatible audio files through the Android system file picker for local playback or management. Lyra Recorder accesses only the file deliberately selected by the user and does not search unrelated folders or files. The current version does not automatically share recordings with Ancient BitForge or other parties.

Deleting a recording created by Lyra Recorder removes the corresponding local file when Android grants the required access. Deleting an imported item from within the Application may also delete the selected local file if Android permits that operation; users should keep a separate copy when they wish to preserve the original.

6. TRIAL INFORMATION

The 21-day evaluation period is enforced with local trial-state information, including timestamps and status values stored on the device. This information is used only to determine the evaluation period and reduce manipulation of the device clock.

Where supported, the Application protects trial-state information with Android EncryptedSharedPreferences. If encrypted storage is unavailable, Android application preferences may be used as a fallback. Trial information is not used for advertising, analytics, location tracking, cookies or network profiling.

7. RETENTION AND DELETION

Recordings and markers. These remain on the device until the user deletes them, clears the Application’s data or uninstalls the Application. Files stored outside the app-specific area, including imported originals, may remain after uninstallation and must be managed by the user through Lyra Recorder, Android or another file-management tool.

Preferences, calibration and trial state. These remain locally until the user clears the Application’s data or uninstalls the Application, subject to any backup or restore behavior enabled by Android or the user’s device account.

Ancient BitForge servers. Ancient BitForge retains none of the above data on its servers because the Application does not transmit it to Ancient BitForge.

Lyra Recorder does not create user accounts; therefore, there is no server-side account or associated cloud data to request for deletion.

8. DATA SHARING

Ancient BitForge does not sell, rent or trade personal or sensitive user data. The Application does not disclose recordings, microphone content, markers, calibration data or settings to Ancient BitForge.

Data leaves Lyra Recorder only when the user deliberately selects an Android system component or another application to access a file or web address. The receiving service is governed by its own privacy policy.

9. SECURITY

Lyra Recorder relies on Android’s app sandbox and app-specific storage controls to protect local Application data. Trial-state information is encrypted where Android support is available. No method of local storage is completely immune to device compromise, unauthorized physical access, malware, operating-system vulnerabilities or user-configured backup services. Users should protect their device with current security updates and an appropriate screen lock.

10. CHILDREN’S PRIVACY

Lyra Recorder is not directed specifically to children under 13. Ancient BitForge does not knowingly collect personal information from children through the Application. Because recordings remain local, a parent or guardian can delete them from the device using the methods described above.

11. CHANGES TO THIS POLICY

This Privacy Policy may be updated when the Application’s features, permissions, data practices, billing implementation, legal requirements or support details change. The current version will be published at the public policy URL shown below. Material changes will be reflected by a revised “Last updated” date.
