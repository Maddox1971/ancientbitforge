ANCIENT BITFORGE — MULTILINGUAL PACKAGE

Languages, in commercial priority order:
EN · DE · JA · KO · ES

CONTENTS
- 20 complete HTML pages:
  - 5 Home pages
  - 5 Lyra BitPerfect pages
  - 5 Lyra Recorder pages
  - 5 Arrival pages
- language.css
- Canonical and hreflang metadata
- Language selector on every page
- Root-relative links to the existing shared CSS, assets, videos and documents

INSTALLATION
1. Make a backup of C:\development\ancientbitforge
2. Extract the CONTENTS of this package directly into:
   C:\development\ancientbitforge
3. Allow replacement of the four existing English index.html files.
4. Do not delete the existing styles.css, app CSS files, assets, videos or documents.
5. Start Live Server from the repository root.
6. Test:
   /
   /de/
   /ja/
   /ko/
   /es/

IMPORTANT
The package intentionally uses root-relative routes beginning with /.
They work correctly under Live Server and on ancientbitforge.com.
